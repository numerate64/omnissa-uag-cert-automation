Horizon UAG Certificate Automation

Renew a public Horizon certificate with win-acme, validate through AWS Route 53, and upload the replacement certificate to Omnissa Unified Access Gateway.

Public endpoint https://horizon.example.com:8443
Automation host Windows host running wacs.exe
UAG admin API https://uag-admin.example.local:9443

Install Checklist

  1. Install win-acme plus the Route 53 validation plugin on the Windows automation host.
  2. Copy this folder to C:\CertAutomation on that host.
  3. Copy settings.example.json to settings.json.
  4. Fill in the UAG username/password and PFX password fields.
  5. For a clean setup or key rotation, run the one-time win-acme Route 53 setup command so win-acme stores AWS credentials and saves the renewal ID.
  6. Run validation first, then a renewal without upload, then upload-only.
  7. Import the Task Scheduler XML after the manual run succeeds.

Dependencies

  • Windows PowerShell 5.1 or PowerShell 7+.
  • win-acme pluggable release with the Route 53 validation plugin.
  • AWS Route 53 hosted zone and least-privilege DNS validation key or role.
  • UAG admin API access on port 9443.

UAG Certificate Target

Use END_USER for the public Horizon interface. Add ADMIN only if you also want the admin console certificate replaced.

Commands

Create folders

New-Item -ItemType Directory -Force C:\CertAutomation
New-Item -ItemType Directory -Force C:\CertAutomation\certs

Validate configuration

powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\CertAutomation\renew-and-push-uag.ps1 -ConfigPath C:\CertAutomation\settings.json -ValidateOnly

Initialize Route 53 credentials and upload

powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\CertAutomation\Initialize-WinAcmeRoute53Renewal.ps1 -ConfigPath C:\CertAutomation\settings.json -RunRenewAndPush

Noninteractive test with environment keys

$env:AWS_ACCESS_KEY_ID = "<route53-access-key-id>"
$env:AWS_SECRET_ACCESS_KEY = "<route53-secret-access-key>"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\CertAutomation\Initialize-WinAcmeRoute53Renewal.ps1 -ConfigPath C:\CertAutomation\settings.json -Force -RunRenewAndPush

Renew without UAG upload

powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\CertAutomation\renew-and-push-uag.ps1 -ConfigPath C:\CertAutomation\settings.json -SkipUpload

Upload existing certificate files

powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\CertAutomation\renew-and-push-uag.ps1 -ConfigPath C:\CertAutomation\settings.json -UploadOnly

Full unattended run

powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File C:\CertAutomation\renew-and-push-uag.ps1 -ConfigPath C:\CertAutomation\settings.json
